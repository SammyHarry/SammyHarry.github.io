# Weavin Public Page Templates

Status: hostable pages for the App Store support and privacy URLs. These pages use the in-app support email address and target Sam Harrington's GitHub Pages site.

## Files

- `index.html`: simple public landing page with links to support and privacy.
- `support.html`: App Store support URL candidate.
- `privacy.html`: App Store privacy policy URL candidate.
- `styles.css`: shared static styles.

## Before Publishing

1. Confirm the privacy copy with the owner/legal reviewer.
2. Confirm provider details and retention settings for Supabase, OpenAI, SerpApi, and the backend host.
3. Verify the support and privacy URLs load in a signed-out/private browser.
4. Enter the final URLs in App Store Connect.
